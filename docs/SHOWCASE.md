# Showcase capture notes

The README images are captures of the running application, not design mockups. They use only synthetic demo data.

## Reproduce the preview

Start the Python service and Next.js using the README. Upload `examples/project-notes.txt` (named `showcase-notes.txt` in the capture), select it, and ask `When is the deadline?`. Inspect the extractive response and citation. No model or external integration is connected.

## Interpretation

Screenshots document the visible state of this development scaffold. They do not imply a public deployment, production readiness or completion of planned features. See the README for implemented scope and validation.
